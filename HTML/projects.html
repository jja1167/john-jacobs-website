Vacation App

A mobile app built for Android devices that allows a user to track important information about their vacation, such as the hotel they are staying at, start and end dates, and any excursions they have planned. The app also allows the user to set reminders for important dates, such as start and end dates or date of an excursion. It also has a sharing feature, so the user can share all the vacation information with their family or friends. The app was built using Java, and it uses a SQLite database to store the user's information. View on GitHub
